# 지능 제 1 가설 ["The First Hypothesis of Intelligence"]

-1. 왜 지능을 하나의 물리량으로 정의할 필요가 있는가?

-> 자연계에는 인간이 지능이라고 불러 온 다양한 현상이 존재한다.

-> 그러나 이 현상들이 존재한다는 사실만으로 지능이라는 독립적인 물리량이 필요하다고 결론 내릴 수는 없다.

-> 그렇다면 기존의 물리학적·수학적 설명만으로는 충분히 통합하거나 예측하기 어려운 공통적인 현상이 존재하는가?

-> 그러한 현상이 존재한다면, 하나의 정량적 관계를 도입함으로써 그 현상들을 더 정확하게 설명하고 새로운 조건에서의 결과를 예측할 수 있는가?

-> 반대로 그러한 관계를 도입하지 않아도 모든 필요한 설명과 예측이 가능하다면, 지능을 별도의 물리량으로 정의할 이유는 무엇인가?[그런 예측 실패 사례가 아직 발견되지 않았다는 사실은 지능의 물리량이 존재하지 않는다는 증거는 아님]

-> 기존 물리학적 변수와 동역학적 모델로 기술할 수 있는 현상들 가운데, 우리가 지능이라고 불러 온 계들의 미래 반응을 예측할 때 공통적으로 나타나는 한계가 존재하는가?

-> 그 한계는 단순한 관측 부족이나 계산 복잡도에서 발생하는가, 아니면 서로 다른 물리계에 공통으로 적용할 수 있는 정량적 성질을 정의함으로써 개선할 수 있는가?

-> 그러한 성질이 존재한다면, 그 성질은 기존의 변수만으로 구성한 예측보다 미관측 조건에서도 더 나은 예측을 제공하는가?


[복잡한 물리계에서 모든 미시 변수를 직접 추적하지 않고도, 새로운 외란에 대한 상태 전이 궤적의 유지·이탈·복원 여부를 예측할 수 있는 일반화 가능한 정량적 성질이 존재하는가?
그러한 성질이 존재한다면, 그것은 기존의 에너지·엔트로피·안정성·제어가능성 등의 측정량보다 더 간결하거나 정확한 예측을 제공하는가?]


[\(a\)와 \(\delta a/\delta C\)가 실재한다면, \(a\)의 스케일링 하나만으로 미관측 환경의 붕괴를 단언할 수 있다.]



0. 지능을 물리적 수치로 정의할수있는가?


1.  사고라는 개념을 전혀 사용하지 않아도, 우리가 지능이라고 불렀던 현상에서 공통적인 무엇인가를 관측할 수 있는가? 

2. 자연계에 아직 명확히 정의하지 못한 어떤 성질이 존재하고, 사고는 그 성질이 특정한 시스템에서 발현되는 하나의 현상일 수도 있다. 

3. 지능의 척도로 인간이 흔히 사용하는 천재와,바보라는 수식어를 놓고 봤을때 천재와 바보를 규정하는 모든것을 덜어낸다

3.6 돌, 다이아몬드, 온도감지기, 화재경보기, 화약통 박테리아 등을 '지능이 아니다'라고 배제할 물리적 근거는 없다

4. 더 나아가서 존재만 남겨놓고 모든 자연계에 존재하는 것들을 본다


5. 자신의 상태를 알리는 것은 남을수 있다(다른 계와의 상호작용에서 상태 차이가 구별 가능한 영향을 남길 수 있다)

-> 상태 ($S$): 계가 현재 점유하고 있는 물리적 배치 (위상 공간 좌표) , 또한 상태 전이 자체에는 지능이 필요하지 않다.

-> 상호작용 ($X$): 계 안팎에서 상태를 바꾸는 물리적 힘/작용의 교환 , 또한 전달 자체에도 지능이 필요하지 않다.


-> 그렇다면 존재하는 시스템의 상태 차이는 상호작용을 통해 다른 시스템에 구별 가능한 영향을 남길 수 있다.
